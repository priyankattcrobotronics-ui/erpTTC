Run Command:-
    php artisan migrate:fresh
    php artisan db:seed

Seeder:-
    RoleSeeder → Creates the default roles such as Admin, Sale, Purchase, Production, Account, etc.
    AdminUserSeeder → Creates the default admin login user.
    DatabaseSeeder → Controls which seeders should run and in what order.
Migration:-
    Migration is used to create and modify the database structure.
